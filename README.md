# Presence Studio

Приложение для Windows, с которым можно создать свою активность в Discord с названием, описанием, изображением и таймером.

## Запуск

1. Установи [Python 3.10 или новее](https://www.python.org/downloads/windows/) с компонентом Tcl/Tk. При установке с python.org можно выбрать «Add Python to PATH».
2. Открой настольный Discord, войди в аккаунт и включи показ активности в настройках конфиденциальности.
3. Открой [Discord Developer Portal](https://discord.com/developers/applications), создай приложение и скопируй **Application ID** из **General Information**.
4. Дважды щёлкни по `Start.pyw`, чтобы открыть программу без консоли. Для запуска из терминала выполни `python app.py` в папке проекта.
5. Вставь Application ID, заполни название и нажми **Опубликовать**.

Сторонние пакеты Python не требуются. Подключение происходит через локальный канал настольного Discord. Токен аккаунта и секрет приложения не нужны.

## Настройка активности

- Во все поля можно вставить текст через **Ctrl+V** или команду **Вставить** в меню правой кнопки мыши.
- Длительность задаётся в минутах от 1 до 1440. При значении **0** таймер показывает прошедшее время, а активность остаётся до ручного снятия или закрытия Presence Studio.
- Для картинки используй прямую публичную HTTPS-ссылку или ключ изображения. Чтобы получить ключ, загрузи картинку в настройки Rich Presence своего приложения в Developer Portal. Предпросмотр показывает текст и источник картинки. Саму картинку отображает Discord.
- Название передаётся в поле названия и в строке деталей. Если Discord оставляет в шапке имя из Developer Portal, выбранное название отображается в строке деталей. Чтобы изменить имя в шапке, измени имя приложения в портале.
- Последние настройки хранятся в `%LOCALAPPDATA%\PresenceStudio\settings.json`. Discord получает данные опубликованной активности и PID Presence Studio.

## Файлы

- `app.py` — окно, настройки, таймер и управление публикацией.
- `discord_rpc.py` — обмен сообщениями с настольным Discord.
- `Start.pyw` — запуск двойным щелчком без консоли.

Для публикации на GitHub загрузи содержимое этой папки в отдельный репозиторий.
